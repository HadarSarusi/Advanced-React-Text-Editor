## 📌 Project Overview 📌

This project is an **advanced web-based multi-file text editor**  
built using **React + Vite**, designed to demonstrate:

- Complex state management
- Modular component architecture
- Undo/Action handling logic
- Multi-file editing system
- Advanced UI interaction flows

This is not just a text box —  
it is a **state-driven frontend system**.

---

## 🎯 Core Features 🎯

### 📂 Multi-File Editing
- Create and manage multiple editable files
- Switch between files dynamically
- Maintain independent content per file

### 🔁 Undo System
- Action-based history tracking
- Revert previous text operations

### 🧹 Text Manipulation Tools

- User-based UI flow simulation
- Session-based interface logic

## 🏗 Architecture Philosophy 🏗

This project focuses on **component separation and state isolation**.

Each responsibility is modular:

- `TextEditor` → Core state orchestration
- `EditableFile` → Individual file logic
- `FindBar` / `ReplaceBar` → Search logic
- `DeleteActionsBar` → Action management
- `UndoButton` → History interaction
- `TextStyleBar` → Styling control

The architecture demonstrates:

- Controlled prop drilling
- UI logic separation
- State mutation patterns
- Component-level responsibility design
